# 政府和公共服务地点验证：一名学生操作说明

本轮验证沿用既有160个Vermont地点，用于改进分类定义和发现误判。
每条地点需要判断政府/公共服务属性、服务类型、是否面向公众，并记录证据。
学生只接收 student_send_now 目录；研究者保留抽样主表、重复编码表和对应密钥。

## 工作安排

1. 阅读随附代码本，先试填20条。遇到不清楚的定义记在 coder_notes。
2. 明确定义后完成其余140条。如修订代码本，记录版本并重查受影响的已编码条目；
   本轮属于方法开发，不能再当作未参与调参的独立测试集。
3. 首轮完成后保留原文件，研究者冻结文件并记录完成日期。
4. 间隔7–14天，再接收一张40条的空白复核表。该时间间隔是工作安排，不是统计学门槛。
   不查看第一轮答案。新表使用不同ID和顺序，但地点名称仍可能被记住。
5. 研究者比较两轮；不一致的条目查证后另存最终判定，保留两轮原始答案。

首轮160条加复核40条，总计200次判断。先用前20条的实际耗时估算安排；
疑难项每条查5–10分钟仍无法确定时，填写 uncertain 并说明缺少什么证据。

## 判断顺序与字段

逐条回答：谁运营？提供什么服务？公众如何接触？这个具体Google地点是否就是该机构？
市政厅旁边的咖啡馆、消防博物馆、医院内商店不能因地址相邻就归入政府机构。

| 字段 | 填写要求 |
|---|---|
| coder_id | 固定匿名编号，例如 student_01 |
| coded_at_utc | 本条编码日期/时间，统一使用UTC并注明Z，例如 2026-09-21T15:00:00Z |
| public_sector_label | yes / no / uncertain；代表政府或有证据的受托公共服务机构 |
| ownership_status | public / contracted_public_service / quasi_public / private_regulated_only / uncertain |
| service_family | 具体服务，如 motor_vehicles、postal_service、court、police、public_library；多种用分号分隔，不清楚填 uncertain |
| public_facing | yes / no / uncertain；警察、消防等非窗口式服务也可有真实公众接触 |
| analytic_tier | core / secondary / separate_sector / exclude / uncertain，遵循代码本 |
| evidence_url | 支持判断的网页链接，优先政府/机构官网；多个用分号分隔 |
| evidence_note | 简短说明网页如何证明该地点的运营者、地址或服务；不能只写“看起来像” |
| evidence_vintage | supports_2021 / current_only / unknown；当前官网不能自动证明2021年状态 |
| exclusion_reason | 私营、纪念设施、同址其他商户、无人设施等具体原因；无须排除则留空 |
| coder_notes | 歧义、查询困难、历史状态变化等；无法核实时记录搜索词/来源 |

work_item_id、地点信息和 codebook_version 不要修改。不要删行或因无评论而排除机构。
所有 yes/no 判断尽可能附证据；不能找到依据就标 uncertain，保留疑难项。
医院、学校、救护服务和非营利机构尤其需要核查运营主体。
机构属于公共部门与其评论能否进入某个分析是两个字段，分别回答。

可以自行搜索机构官网。不要查看程序预测、匹配得分、抽样层或研究者对应密钥。
AI可协助提出搜索词或整理链接；若使用，应在 notes 记录并由学生核实原网页。
AI回答不能充当第二个人工编码者。

## 研究者如何使用结果

同一个人的重复判断评估“编码者内稳定性”，不能称作双人独立一致性。
先报告一致率、混淆表和每类条数；可补充重测kappa，单一类别时kappa可能无定义。
不一致项/uncertain项进入证据核查清单，不强制变成yes或no。

本轮不是全国精度认证。40条普通负样本用于发现遗漏，不能据此声称“找全了”。
按二项模型，40条零遗漏时，遗漏比例的单侧95%上限仍约7.2%；这不是召回率。
正式总体估计需使用抽样权重和适当的有限总体/分层不确定性计算。
参考：[NIST比例置信区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

之后从全国候选、疑难项和未入选地点中另外抽样，按服务类型和区域分层。
样本量按首轮错误、稀有类别和目标置信区间确定；所有调参数据与最终评估数据分开。
论文明确披露一名学生编码、40条延迟重测，以及缺少独立双人验证的限制。
